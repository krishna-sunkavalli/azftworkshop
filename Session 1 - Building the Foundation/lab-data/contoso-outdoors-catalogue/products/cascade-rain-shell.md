# Cascade Rain Shell

**SKU:** CO-APP-CRS
**Category:** Shells / Apparel
**Effective date:** 2026-01-15

## Specifications

| Attribute | Value |
|---|---|
| Membrane | 3-layer waterproof breathable laminate |
| **Waterproof rating** | **20,000 mm HH** |
| Breathability | 20,000 g/m²/24h (MVTR) |
| Weight | 385 g (men's M) |
| Seams | Fully taped |
| Hood | Adjustable, helmet compatible |
| Pit zips | Yes |
| Sizes | XS-XXL (men's), XS-XL (women's) |

> Do not confuse a **shell** rating with a **tent fly** rating. Garment
> membranes are rated far higher than tent flies because a garment is
> subject to direct pressure from pack straps and body contact.

## Care

See [Waterproof fabric care](../care/waterproof-care.md). DWR needs
periodic renewal; a shell that "wets out" is usually not a failed
membrane.
