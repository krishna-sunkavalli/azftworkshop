# Basecamp Stove

**SKU:** CO-CKG-BCS
**Category:** Cooking
**Effective date:** 2026-01-15

## Specifications

| Attribute | Value |
|---|---|
| Type | Canister-top stove with integrated igniter |
| Fuel | Isobutane/propane mix canisters (screw thread) |
| Output | 3,000 W (10,200 BTU/h) |
| Boil time | 3 min 20 s per litre at sea level |
| Weight | 118 g |
| Simmer control | Yes |

## Safety

- Never operate inside a tent, vestibule, or any enclosed space.
- Allow the burner to cool fully before packing.
- Fuel canisters cannot be shipped by air. See
  [Shipping and delivery](../policies/shipping-policy.md).
